# Owner decisions

The release uses conservative defaults so a safe portfolio Preview can proceed.

## Approved initial defaults

- Public name: **CodeClarity AI**.
- Tagline: **Test your skills. Understand every answer.**
- Repository: `princeinoba/bootcamp-homework4`.
- Production branch: preserve `master` while it remains the repository default.
- Vercel project: `codeclarity-ai`.
- No account, database, analytics or public leaderboard.
- Progress and leaderboard remain browser-local.
- Deterministic Study Coach is the complete Production mode.
- Public indexing remains disabled.
- Stable Vercel-generated domain is acceptable for the initial release.
- No clean-room licence is assigned yet.

## Decisions required before broader promotion

1. Approve long-term use of the CodeClarity AI name and local artwork.
2. Select a clean-room licence before third-party redistribution.
3. Decide whether the original bootcamp repository should retain or archive the historical implementation in Git history.
4. Conduct editorial review of all 36 questions and explanations.
5. Decide whether normal search indexing should be enabled.
6. Decide whether a custom domain is needed.
7. Decide whether Preview live AI is worth provider processing and cost.
8. Before Production live AI, approve the model, provider, data processing, budget, abuse controls and evaluation cases.
9. Define whether a future product needs accounts, cross-device progress, instructors, organizations, certifications or code execution.
10. Define privacy, retention, moderation, support, monitoring and incident response before any shared learner profile.
